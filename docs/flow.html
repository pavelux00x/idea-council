How idea-council works, step by step

You write the idea, the skill asks a few questions once, quotes the run, then an Opus 5.5 chairman drives ten council members through a blind round, a context round and an anonymous review before writing the verdict.

    Setup and intake

    first run only, or on “setup”
    YouYouthe userYour sessionClaude Code or pi

    • The session asks with interactive questions: where is the OpenRouter key file (path only, never read), do you have an AIsa key and may it be used, Herdr / subagents / local models, how many external models and which, the 4 Claude roles yes or no, web search in round 1, who plays devil's advocate.
    • Answers are saved locally; next runs only show the setup in one line and ask “keep or change?”.

    Preflight and quote

    no paid call yet
    Your sessionClaude Code or piYouYouthe user

    Fact dossier

    chairman + researchers
    ChairmanOpus 5.5 · Herdr tabSonarPerplexitySonar Reasoning ProPerplexity
    • The chairman reads the run folder, then researches the five points itself: who already does this, claimed vs independently measured results, format saturation, platform rules, your own data. Tools: web search, AIsa if allowed, helpful local skills.

    Round 1, blind

    no team opinions
    ChairmanOpus 5.5 · Herdr tabpyScriptopenrouter_council.pyDeepSeek V4 ProGemini 3.8 FlashGPT 5.6 TerraQwen 3.7 PlusKimi K2.5Grok 4.3devil's advocateSkepticSonnet 5.5MarketSonnet 5.5CreativeOpus 5.5NumbersOpus 5.5
    • The chairman starts the script (6 external models, web search on, Grok attacks the idea) and opens 4 Herdr panes with the Claude roles.
    • Every member answers every numbered question in a fixed format: evidence for, evidence against, load-bearing assumption and “fails if…”, verdict with score, improved version and cheapest test with a kill criterion. Every claim cites F# or N# (new fact with URL) or is marked unverified.
    • The script checks each answer (all questions, verdict line, length, break-even number used) and retries once with the list of problems; what still fails is marked weak.

  5. 3

    Round 2, with context

    opinions revealed
    ChairmanOpus 5.5 · Herdr tabpyScriptopenrouter_council.pyDeepSeek V4 ProGemini 3.8 FlashGPT 5.6 TerraQwen 3.7 PlusKimi K2.5Grok 4.3devil's advocateSkepticSonnet 5.5MarketSonnet 5.5CreativeOpus 5.5NumbersOpus 5.5
    • The chairman verifies the N# facts and folds them into the dossier, then everyone rewrites the complete answer with context-opinions.md and their own round 1 in view. No web search now.
    • A member that changes verdict must say whether a new fact or only the team's opinions caused it. A change without a fact is a sycophancy signal and goes in the report.
    • The chairman reads every answer for arithmetic that contradicts the calc, facts cited wrongly, invented tools or prices.

    Wrong answer? The chairman re-runs that member with a precise note (--only slug --note "…", or hc send to a Claude pane), at most twice, then discards it and says so in the report.

  7. 5

    Verdict

    evidence, not vote count
    ChairmanOpus 5.5 · Herdr tabYouYouthe user
    • The chairman writes report.md, at most one page per question, verdict first: GO / NO-GO / GO WITH CHANGES with score and confidence, the numbers, the facts that matter, load-bearing assumptions with kill criteria, what is well-reasoned, improved version, minimal test, where the council disagreed and whom the chairman sided with, what could not be assessed, costs and exact model ids.
    • It may side with a single dissenter if its facts are stronger.
    • eval_run.py runs nine deterministic checks and the result goes in the report as is. Then the chairman sends you the summary and the path; an Artifact or Notion page is optional.
    report back to youreport.md · costs.json · test-log.md
